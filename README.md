# Hospital Readmission Predictor

## Project Description
This project predicts whether a patient is likely to be readmitted to the hospital using Machine Learning.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

## Features
- Predicts hospital readmission
- Simple and easy-to-use interface
- Instant prediction
